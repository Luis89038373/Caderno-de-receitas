# Checklist de Responsividade

Regra oficial: o mesmo site deve ser totalmente utilizável em PC e celular.

## PC
- [x] Catálogo em múltiplas colunas
- [x] Página de receita com foto e conteúdo lado a lado quando houver espaço
- [x] Busca e filtros visíveis
- [x] Imagens sem deformação

## Tablet
- [x] Grade reduzida automaticamente
- [x] Página de receita reorganizada conforme a largura
- [x] Acervo ajusta número de colunas

## Celular
- [x] Menu móvel acessível por botão
- [x] Catálogo em uma coluna
- [x] Foto da receita ocupa a largura disponível
- [x] Ingredientes passam para leitura vertical em telas pequenas
- [x] Modo de preparo permanece numerado e legível
- [x] Busca e filtros ocupam largura total
- [x] Botões e links têm área mínima de toque
- [x] Sem rolagem horizontal de layout

## Breakpoints utilizados
- acima de 1024 px: desktop
- 761–1024 px: tablet / notebook compacto
- até 760 px: celular / tablet estreito
- até 520 px: celular compacto
- até 360 px: telas muito estreitas
